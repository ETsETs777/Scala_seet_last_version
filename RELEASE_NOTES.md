# Release v1.3.0

## Overview
Comprehensive Scala application demonstrating best practices and advanced language features.

## Features

### Core Models
- User model with validation and age groups
- Product model with status management

### Services
- UserService with CRUD operations, search, pagination
- ProductService with inventory management, discounts, sales

### Advanced Features
- JSON serialization/deserialization
- Event Bus system for event-driven architecture
- Metrics collection and monitoring
- Pagination support
- File service for file operations
- CSV export/import
- Repository pattern with in-memory caching

### Functional Programming
- Monad examples (Option, Try, Either)
- Higher-order functions
- Type classes
- Pattern matching

### Utilities
- Extensions for String, Int, List, BigDecimal
- DateTime utilities
- Collection utilities
- Logger with multiple backends

## Installation

```bash
sbt compile
sbt run
sbt test
```

## Requirements
- Java JDK 8+
- Scala 2.13.12
- sbt 1.9.7
