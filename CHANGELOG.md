# Changelog

Все значимые изменения в проекте документируются в этом файле.

## [1.2.0] - 2025-01-XX

### Добавлено
- Интеграция логирования во все сервисы (Logger)
- Методы экспорта/импорта данных в CSV формате для UserService и ProductService
- Методы работы со скидками в ProductService: `applyDiscount`, `applyDiscountByStatus`
- Репозиторий паттерн: базовый интерфейс Repository и InMemoryRepository с кэшированием
- Новые методы в UserService: `getUsersByAgeGroup`, `deactivateUsersOlderThan`
- Улучшенная валидация при обновлении пользователей
- Демонстрация новых возможностей в Main.scala

### Улучшено
- Обработка ошибок в сервисах с подробным логированием
- Валидация данных при добавлении продуктов (проверка цены и количества)
- Логирование всех операций CRUD в сервисах
- Обработка ошибок при импорте CSV данных

### Исправлено
- Исправлена структура класса UserService (методы были вне класса)

## [1.1.0] - 2025-01-XX

### Добавлено
- Полная ScalaDoc документация для всех основных классов и методов
- Методы поиска в UserService: `searchUsers`, `emailExists`, `getUsersSortedByAge`
- Методы поиска в ProductService: `searchProductsByName`, `getLowStockProducts`, `getTopExpensiveProducts`
- Улучшенная валидация email с использованием регулярных выражений
- Дополнительные демонстрации новых возможностей в Main.scala

### Улучшено
- Добавлены ScalaDoc комментарии ко всем моделям данных (User, Product)
- Добавлена документация к сервисам и их методам
- Улучшена валидация email: более строгая проверка формата и длины
- Улучшен Main.scala с демонстрацией новых методов поиска и фильтрации
- Оптимизирована обработка данных (trim, toLowerCase при создании пользователей)

### Исправлено
- Исправлена валидация email: теперь используется полноценный regex вместо простой проверки наличия символа '@'
- Нормализация email: автоматическое преобразование в нижний регистр при создании

## [1.0.0] - 2025-10-31

### Добавлено
- Базовые модели данных (User, Product)
- Сервисы для управления пользователями и продуктами
- Примеры функционального программирования с Option, Try, Either
- Функции высшего порядка и композиция функций
- Type classes и implicit parameters
- Асинхронное программирование с Future
- Расширенные методы для моделей данных
- Система валидации и обработки ошибок
- Дополнительные unit-тесты
- Утилиты для работы с коллекциями
- Система конфигурации
- Улучшенная документация кода (ScalaDoc)
- Поддержка различных возможностей Scala 2.13

### Улучшено
- Документация кода с подробными комментариями
- Обработка ошибок и валидация данных
- Структура проекта и организация кода
